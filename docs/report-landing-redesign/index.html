Smell audit

  • Fixed — padding fought itself. .hero{padding:40px 0 44px} vs JSX px="md": two rules over one shorthand, resolved by specificity. Now padding-block in CSS, padding-inline on .bleed, prop gone.
  • Fixed — two magic rgba(255,255,255,…) tints written inline in JSX, invisible to the stylesheet. Now .onPitch / .quiet.
  • Fixed — fixture card truncated to 1… 3… 2… at 375px, and stretched to a tall empty box at 1280. Caught by screenshot, not by any test. Rebuilt as a labelled betting slip; grid no longer stretches it.
  • Kept — style={{alignItems:"center"}} inline on one SimpleGrid. One property, one caller, clearer at the call site than a class named for it.
  • Kept — cta(size) returns JSX from a param. Two callers, two sizes. A component for it would be abstraction nobody asked for.
  • Kept — SIDES/PRICES are untyped tuple arrays (string[][]). Same shape FIRST_STEPS already used. A named type buys nothing at this size.
  • Deprecated-API checker: not run. It is a pyright rule in the backend gate; this diff is frontend-only and touches no Python.
  • Dead CSS: checked every rule in the module has a caller. None dead.
